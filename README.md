## Built With

This site leverages a modern tech stack for optimal performance and developer experience:

### Core Framework
- **[Astro](https://astro.build/)** - Static site generator with zero JS by default
- **[TypeScript](https://www.typescriptlang.org/)** - Type safety and enhanced developer experience

### UI & Styling  
- **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first CSS framework
- **[SolidJS](https://www.solidjs.com/)** - Reactive UI components where needed
- **[Qwik](https://qwik.builder.io/)** - Resumable framework for interactive elements

### Animation
- **[GSAP](https://greensock.com/gsap/)** - Smooth animations and transitions

### Deployment & Hosting
- **[Netlify](https://netlify.com/)** - Fast, reliable hosting and CI/CD
- **CDN Optimization** - Global content delivery for lightning-fast load times

## Development

### Prerequisites
- Node.js 18+ or Bun
- NPM, Yarn, or Bun package manager

### Getting Started

```bash
# Clone the repository
git clone [repository-url]
cd personal-website

# Install dependencies
npm install
# or
bun install

# Start development server
npm run dev
# or  
bun run dev
```

### Available Scripts

```bash
# Development server with hot reload
npm run dev

# Type checking and build for production  
npm run build

# Preview production build locally
npm run preview

# Check TypeScript and Astro issues
npm run astro check
```
